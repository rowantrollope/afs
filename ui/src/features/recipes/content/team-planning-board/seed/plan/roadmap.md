# Roadmap

Phases and milestones. Snapshot the workspace with
`afs checkpoint create team-board --name milestone-<slug>` each time you finish
a milestone so the timeline is recoverable. Replace `team-board` with your
workspace name. Other machines must publish their edits before you capture the
checkpoint; the command flushes only this machine’s matching mounts.
