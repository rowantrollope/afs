# Memory index

Append new entries below the newest date heading. Keep each line under
140 characters — title plus a one-line summary and a link to the full
entry file. Coordinate index edits through one writer when agents work
concurrently. Individual entry files are the source of truth; an index update
is not an atomic append across machines.
